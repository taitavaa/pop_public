# Pop

Chaotic bubble-popping in Godot 4.  
Click bubbles, trigger chain reactions, and push your score before pops run out.

## Highlights
- Limited pops per run = meaningful choices
- Explosive bubbles that pop neighbors
- Chain depth bonuses and score multipliers
- Live HUD for pops, score, and breakdown text
- Tunable gameplay values for quick balancing

## Tech
- Engine: Godot 4.6
- Language: GDScript
- Main scene: `scenes/grid.tscn`

## Run
1. Open the project in Godot
2. Press **Play**
3. Pop bubbles, build chains, chase high scores
